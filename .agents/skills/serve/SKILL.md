# Serve Worktree Workflow

이 워크플로우는 사용자가 새로운 워크트리에서 개발 현황을 확인하고자 할 때 로컬 서버를 띄우는 작업을 자동화합니다.

## Steps

1. **`.env.local` 파일 확인 및 복사**:
   현재 워크트리(디렉토리)에 `.env.local` 파일이 존재하는지 확인합니다.
   만약 없다면, 부모 레포지토리(메인 워크스페이스)에서 `.env.local` 파일을 찾아 현재 워크트리로 복사합니다. (AGENTS.md 규칙 준수)
2. **포트 3001 로컬 서버 실행**:
   `npm run dev -- -p 3001` 또는 현재 프로젝트 환경에 맞는 명령어를 백그라운드 태스크로 실행하여 3001 포트에서 서버를 시작합니다.
3. **상태 보고**:
   서버가 정상적으로 실행되었는지 확인하고, 사용자에게 로컬 서버 접속 주소(예: `http://localhost:3001`)를 안내합니다.
